⚠️ Kenapa Kemarin Malah Ter-download?

Jika file .py ditaruh sembarangan di folder root tanpa struktur Vercel, Vercel memperlakukannya seperti file biasa (dokumen unduhan). Akibatnya:

  • Browser tidak mengeksekusi Python, melainkan mendownload file script tersebut.
  • Layar jadi putih kosong karena tidak ada index.html sebagai tampilan utama.

✅ Kenapa Repo Ini Pasti Berhasil?

Repo ini sudah menggunakan standar resmi arsitektur Vercel:

  • index.html di root: Langsung tampil visual tanpa layar putih.
  • api/index.py: Otomatis dieksekusi Vercel sebagai Serverless Function.
  • Zero Dependencies: Tidak butuh install pip/requirements, langsung jalan!

Langkah Teman Kamu untuk Deploy ke Vercel:

1

Clone atau Fork Repo Ini

Bisa di-fork langsung ke akun GitHub miliknya, atau clone ke komputer lalu push ke repo GitHub sendiri.

2

Buka Vercel (vercel.com)

Login menggunakan akun GitHub, lalu klik Add New... ➜ Project.

3

Import & Langsung Klik Deploy

Pilih repo ini, tidak perlu utak-atik pengaturan build, langsung klik Deploy. Selesai!
